## 1. What H1 proves

H1 proves that the application can run the same sealed caller-audio artifact and the same sealed continuity packet through:

- OpenAI Realtime using browser WebRTC audio-in/audio-out; and
- Gemini Live using a persistent browser WebSocket with PCM audio input and streamed PCM output.

For both routes:

- the Human Caller Agent was not generated by the provider under test;
- benchmark input was audio, not `input_text`;
- output began playing before the provider response completed;
- no complete-response WAV, base64, JSON-audio, or object-URL output path was used;
- no legacy buffered endpoint or silent provider fallback was used;
- actual provider usage was captured;
- cost was explicitly marked unavailable rather than invented;
- a complete required normalized trace was sealed in the append-only local evidence ledger.

H1 does **not** prove:

- one model is better, faster, cheaper, safer, or more natural;
- multi-turn continuity;
- interruption parity;
- Gemini `goAway` recovery;
- session reuse across multiple caller turns;
- production-grade distributed rate limiting;
- judge or Postgres availability;
- cost parity;
- five-scenario or 100-scenario benchmark readiness.

## 6. Failures encountered and what they proved

The failed attempts remain material evidence:

1. The first OpenAI attempt lacked `playback.first_audio`. It was invalidated. The adapter was changed to emit the boundary from the actual HTML media `playing` event.
2. A later OpenAI attempt transported audio successfully but did not use the frozen context/config hashes. The validator rejected it. This proved the hash gate was active.
3. The first Gemini ephemeral-token request used an Enterprise-only transparent-resumption option. It failed closed before a paid Live session was opened. The unsupported option was removed.
4. Initial Gemini PCM pacing accumulated loop overhead. Pacing was changed to an absolute monotonic schedule, after which sealed-input delivery aligned with the OpenAI fixture duration.
5. The independent Claude judge failed closed for both valid H1 sessions because local `DATABASE_URL` was absent. No judge result was fabricated or treated as complete.

## 7. Remaining blockers

H2 cannot begin until the common turn lifecycle and failure gates are proven:

- immediate stop and output-queue clearing;
- application-level interruption parity;
- no-next-turn-before-playback barrier;
- Gemini `goAway` reconnect using a recorded resumption handle;
- same provider session reused across deterministic caller turns;
- token endpoint request caps and explicit failure-injection tests;
- source-audio mismatch invalidation;
- transport disconnect with no fallback;
- provider payload hashing without secrets.

H3 and the 100 × 2 cohort remain blocked until H2 passes.
